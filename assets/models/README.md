# Optional Blender / GLB models

Place reusable and optimised GLB models in this directory after an asset-loader is introduced. Preferred format is glTF 2.0 binary (.glb), real-world scale in metres, PBR materials and lightweight collision proxies.

Suggested hero assets: furnace shells, overhead cranes, forklifts, harbour unloaders, cooling systems and detailed industrial interiors. Keep licences and attribution beside third-party assets. Do not upload proprietary or unlicensed files.
